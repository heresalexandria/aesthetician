# Preset Library Plan

Chain ordering follows the physical signal path:

**Video:** look (stock/tone/balance) → lens (optics/auto-exposure) → medium
(film grain/damage or cel stack) → transfer (cadence/telecine → ntsc/vhs →
codec passes) → display (interlace/CRT/RF) → presentation (framing, plates,
timestamps, print fade).

**Audio:** source tone → medium (tape/vinyl/optical) → transmission
(radio/phone/codec) → playback device (speaker) → room.
