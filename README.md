# Aesthetician

**A premium archival-media aesthetic engine.** Aesthetician applies era-authentic looks — and sounds — to modern video: VHS in a dozen states of decay, three-strip Technicolor, 16mm news film, Saturday-morning cartoons, dying broadcast signals, early web video, and much more.

It is not a filter pack. Every aesthetic is a physically-motivated simulation of the original signal path (film stock → print → projector, or camera → tape → heads → CRT), with dozens of exposed controls per preset.

- **CLI** for scripted/batch use
- **Electron app** with drag-and-drop, live previews, and full parameter control
- **Audio and video** treated separately or together
